# 商业模式库 · 使用说明（先读这一份）

> **这是什么**：一个**商业模式模式库**——把「市面上到底有多少种盈利/商业模式、各自怎么运作、彼此是什么关系」整理成**一个混合的、有顺序的库**，共六部分、约 28.7 万字、**623 条解析条目 + 43 张半名录／总览卡**。
> **怎么用**：这不是按作者分的合集，而是**同一张桌子上的六份材料**——先读本页索引，再按需要读对应的一份。
> **读完你能**：① 用统一的 6 字段语言描述任意一种模式（本质／钱从哪来／什么时候用／怎么落地／坑／案例）；② 把不同流派的说法归并到同一逻辑；③ 知道每条模式的**证据强度**，不会把推演当原话引用。

## ⚠️ 三条使用纪律（不许放宽）

1. **可信度三档**：① 有 ISBN 可查的（01 部分的 108 条、Slywotzky 52、Gassmann 55、Osterwalder 5）证据最强；② 学术机构框架（魏朱、Hamel、蓝海、平台革命）次之；③ 培训 IP 的网络整理稿（臧其超 36、王昕 16）为单一来源，**按待核实处理**。
2. **不为了凑条目而编造名录**——未获得名录的一律做总览卡并注明原因。**命名解析 ≠ 原书内容**：108 条里有 27 条是命名推演，引用前必须回到纸书核对。
3. **合规红线**：全文用 ⚠️ 标出高风险条目，集中在**预收款与现金流、股权与融资、招商与层级分销**三类。判断标准：是否公开宣传、是否面向不特定对象、是否承诺固定回报、奖励是否来自真实交易利润。
